Real-time safety monitoring system built around YOLOv11 for weapon detection and human pose estimation, wired up to a live dashboard that fires automated alerts.
**Tech:** Python, YOLOv11, Computer Vision, Detection Pipeline, Alerting Dashboard
🔗 https://github.com/Lokesh-069/Safe-SignalV2

---

### 🪪 PramaanX
AI-based fake identity document screening system, built to help flag tampered or fraudulent identity documents as part of a verification pipeline.
**Tech:** Python, AI/ML, Document Verification
